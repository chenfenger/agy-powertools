## 这个工具是干嘛的

**Agy Powertools** 是一个 Antigravity 2.0 的增强插件。它通过本机调试接口直接挂载在客户端内部，读取本地 SQLite 与 JSONL 会话记录，在不修改客户端安装文件、也不打开外部网页的前提下，给 Antigravity 2.0 新增了一些有用的功能。

它主要解决日常使用 Antigravity 时的四个痛点：

1. **界面全英文、阅读密度低**：原生菜单和设置项都是英文；聊天区默认行高和段落间距偏松散，一屏能容纳的代码与工具输出很少。
2. **多步任务缺少清晰的阶段反馈**：Agent 连续调用工具时，要么长时间沉默看不出进展，要么把中间过渡说明一直堆在正文里，干扰阅读最终回答。
3. **没有实时上下文窗口显示**：长对话中看不清上下文占用、缓存命中率、生成速度和单条报错详情，也无法集中查看 5 小时限额、周限额与累计 Token 开销。
4. **对话分叉与改错步骤繁琐**：想修改已发出的提问重试，或者从中间某条满意的回答处另开分支探索不同方案时，缺少顺手的原生入口。

## 功能一览

- **类 Codex 对话体验**：同字号紧凑排版；工作时实时汇报当前进展，整轮完成后自动将中间过程折入顶部用时栏，正文只保留最终回答。
- **上下文圆环与动态速度码表**：在输入框旁提供独立的上下文占用圆环（含缓存复用、压缩次数与 Orchestrator 子模型上下文）和动态指针速度码表（点击查看 `tok/s`、首字延迟与模型/工具用时），并支持在 OpenSSH 远程窗口（`SSH: ...`）中零落盘实时读取远端会话、子智能体与看板统计。
- **无损会话分支与消息编辑**：支持从任意历史回答处一键分叉出新会话（完整继承此前对话与工具记录），支持直接在原消息位置打开原生输入框修改重发。
- **右侧任务进度、常驻目录与未读提醒**：在右侧概览区实时展示任务清单进度、最近工具活动与本轮计时，支持常驻左侧轮次目录，并在后台对话完成时显示任务栏未读数字与高亮提醒。
- **原生界面多语言本地化（简体中文 / 繁體中文 / English）**：支持插件面板与 Antigravity 常用原生侧栏、菜单、快捷键及设置页面的简体中文、繁体中文与英文无闪烁切换。
- **本地用量、请求与额度面板**：在左侧栏新增 `Powertools` 管理页，汇总 53 周用量热力图、模型健康时间线、Token 与参考费用双圆环、请求筛选、报错一键复制、订阅限额进度条与官方参考单价。
- **多账号切换与额度管理（默认关闭）**：基于操作系统原生凭据库本地隔离和切换多个 Google 账号，不落明文令牌；在侧栏底部整合账号快捷切换与原生设置入口，支持 5 小时 / 周限额查看、列表/卡片双视图、拖动排序、凭证校验及耗尽自动切号。
- **免 TUN 应用级独立代理（默认关闭）**：不改客户端安装文件与系统快捷方式，通过协议 / 主机 / 端口三段配置在重启时为 Antigravity 注入代理参数与环境变量，内置 HTTP CONNECT / SOCKS5 连通性测试、可选 `GODEBUG=http2client=0` 缓解 `EOF` 断连以及冷启动未启用一键重启提醒。
- **会话增强与在线校验更新**：支持实验性长上下文目标（`默认` / `256K` / `500K` / `1M`）、可选并行检索与读取引导，以及带 SHA-256 校验与失败自动回滚的应用内更新。

## 安装与卸载

### 环境说明

- 请先安装并至少启动过一次 Antigravity。
- 发行包已内置编译产物，安装过程无需执行 `npm install`，无需管理员权限；优先使用本机 Node.js `>= 22.13`，未安装时自动回退使用客户端自带的 `agy-node`。

### 安装

#### 方式一：复制提示词交给 Agent 自动安装（推荐）

将下面这段话直接发给 Antigravity 或其他可执行本地命令的 Agent：

> 请帮我安装 Agy Powertools：https://github.com/chenfenger/agy-powertools 。克隆这个仓库的 main 分支（不要使用上游 WhiteBr1ck/agy-powertools 的 Releases），先阅读 README 和 docs/INSTALL_AGENT.md，使用项目提供的统一安装器，优先使用已有 Node.js 或 Antigravity 自带运行环境。保留其他插件、账户设置和聊天记录，不要强制退出当前客户端。安装后核对版本并告诉我结果；需要重启时最后提醒我。

详细步骤可参阅 [Agent 安装指南](docs/INSTALL_AGENT.md)。

#### 方式二：命令行手动安装

克隆本仓库（或在 GitHub 页面点 **Code → Download ZIP** 下载解压），在项目目录运行：

```sh
git clone https://github.com/chenfenger/agy-powertools.git
cd agy-powertools
```

然后运行安装器：

Windows（PowerShell）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

macOS / Linux：

```sh
sh ./install.sh
```

本机已有 Node.js `>= 22.13` 时也可直接运行 `node scripts/install.mjs`。安装器不会强制关闭客户端，覆盖安装会保留你已有的设置；完成手头任务后重启一次 Antigravity，左侧边栏出现 **Powertools** 即安装成功。

### 应用内更新

> 本分支没有发布 Releases，应用内的「检查更新」找不到新版本。更新时在项目目录执行 `git pull`，再重新运行安装器即可（覆盖安装会保留设置）。

打开 **Powertools -> 设置 -> 关于**，点击 **检查更新**。发现带完整校验文件的正式版本后点击 **立即更新**，更新器会自动校验、备份旧版、替换文件并确认新版本接入正常；若启动异常会自动回滚至旧版本。

### 卸载

在项目目录执行对应命令即可移除插件程序、注册项、缓存及运行数据（不会影响客户端原有聊天记录、账户和其他插件）：

Windows（PowerShell）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\uninstall.ps1
```

macOS / Linux：

```sh
sh ./uninstall.sh
```

如需在卸载时保留个人配置文件，可在命令末尾加上 `--keep-settings`（例如 `node scripts/uninstall.mjs --keep-settings`）。

## 重点功能详解

### 1. 类 Codex 会话体验：阶段汇报 + 紧凑视图

插件默认开启 **阶段汇报** 与 **紧凑排版**，将日常编码对话调整为接近 Codex 的高密度阅读与反馈节奏：

- **工作时说明进展，完成后自动折叠过程**：模型在连续调用工具期间，会在关键动作前输出一两句简短进展，交代当前发现与下一步操作；等整轮回复全部完成后，插件会自动把中途的阶段说明连同工具调用记录一起收进回答顶部的用时折叠栏，聊天区只保留干净的最终结论。需要复盘细节时，点击每轮用时即可重新展开查看。
- **同字号高密度紧凑视图**：完全保留你在 Antigravity 设置的字体大小，通过将正文行高收紧至 `1.4`、统一段落与分割线间距，并将工具分组与工具记录最小行高收紧至 `24px`，让同一屏幕容纳更多代码和上下文。

下图两侧为同一段回答、相同窗口宽度与 `14px` 字号，仅切换紧凑排版，正文总高度减少约 19%：

![原版排版与紧凑排版对比](docs/images/layout-comparison.png)

### 2. 上下文圆环与动态速度码表

在消息输入框旁提供 **上下文圆环** 与 **速度码表** 两个独立入口（均可在设置中单独开关）：

- **上下文容量与 Orchestrator 拆解**：基于模型实际返回的输入用量计算当前窗口占用比例与压缩次数，细分为消息、系统提示、系统工具、技能与剩余空间，同时展示本步缓存复用上下文与新增输入占比；在 Orchestrator 模式下自动列出规划模型与执行模型各自的上下文进度。
- **动态速度码表与会话统计**：按实时生成速率偏转码表指针并区分颜色，点击可查看本会话轮次与步数、累计 Token、平均 / 峰值 / 最近生成速度（`tok/s`）、缓存命中率、缓存观察窗口估算，以及模型推理总耗时、工具执行总耗时与首 Token 延迟。
- **远程 SSH 窗口统计支持**：在桌面端连接的 `SSH: ...` 远程窗口中，自动复用本机 OpenSSH 配置按需建立零落盘内存只读通道（优先使用远端客户端内置 `agy-node` 或系统 Node.js `>= 22.13`），同步展示上下文圆环、速度码表、右侧任务进度、子智能体统计与远程用量看板，无需在远端服务器安装插件或常驻后台。

### 3. 无损会话分支与消息编辑重发

- **从任意回答创建分支**：每条历史回答的操作栏均提供分支按钮，会话右上角菜单也提供 `分支会话`（同时支持 `/branch-session` 技能），创建后自动将新会话重命名为 `(1)`、`(2)` 加以区分；若会话后续调用过子智能体，会自动提示从子智能体调用前的完整轮次创建无损分支。底层直接调用客户端原生 `ForkConversation` 接口，不额外消耗模型请求，也不会用摘要替代原始上下文。
- **原位原生消息编辑**：点击用户消息旁的编辑按钮即可在该消息原位置展开官方原生富文本输入框，完整保留并支持划词引用（`Ctrl+L`）、`@` 提及与图片粘贴上传，修改发送后自动从该轮重新生成回答（本地工作区内的代码文件不会被回滚）。

### 4. Powertools 本地用量、报错与额度看板

点击客户端左侧栏 **Powertools** 进入独立管理面板，包含五个数据标签页：

- **概览**：默认按客户端原生周限额重置周期精确统计 **本轮周限额内用量**，同时支持按今天、最近 24 小时、昨天、本周、本月、最近 30 天、全部时间或自定义日历范围聚合数据，直观展示请求成功/失败数、累计输入输出 Token、API 等价参考费用、53 周热力图、模型健康时间线、Token 与费用双圆环占比及各模型速度表。
- **请求事件**：按关键词、模型、当前/全部会话与执行状态筛选单次请求，逐行查看速度、首字延迟、输入、缓存读取、缓存命中率、输出与参考费用。
- **错误事件**：集中列出历史失败请求的时间、模型与错误摘要，支持右侧一键复制完整原始报错文本。
- **额度**：读取客户端原生配额接口，显示当前订阅方案铭牌（Pro / Ultra 等）以及 Gemini、Claude / GPT 分组的周限额与 5 小时限额剩余百分比、重置时间和基于本地消耗采样的预算估算。
- **价格**：按模型与思考档位列出每百万 Token 的输入、输出、缓存读取与缓存写入单价，支持一键从 Google AI Studio 和 Google Cloud 官方定价页拉取最新公开费率（仅作参考估算，不代表订阅账单）。

### 5. 原生界面中英双语切换

默认将插件面板及 Antigravity 常用原生界面（侧栏入口、菜单操作、额度提示、快捷键面板和常用设置说明）显示为简体中文，也可在设置中随时切回 `English`。翻译引擎在首屏渲染阶段即介入，避免英文闪烁，同时严格排除消息正文、输入框和代码块，确保对话文本与代码原样呈现。

### 6. 多账号切换与额度管理（可选开启）

该功能默认关闭，可在 **Powertools -> 设置 -> 账号与切换** 中确认风险提示后开启：
- **本地原生凭据库隔离**：通过 Windows 凭据管理器、macOS 钥匙串或 Linux Secret Service 备份与切换多个账号的登录态，不在本地落盘明文令牌，并内置防覆盖锁与凭据哈希查重。
- **侧栏快捷切换与全量管理**：在左侧栏底部整合当前账号头像、套餐铭牌、备注标签与原生「设置」入口，点击可查看各账号 5 小时 / 周限额并一键切换重启；在 **Powertools -> 账号与额度** 页支持列表/卡片双视图、拖动排序、禁用拦截、刷新额度、凭证校验以及可选耗尽自动切号。

### 7. 免 TUN 应用级独立代理（可选开启）

针对不想开启系统全局代理或 TUN 网卡、只想让 Antigravity 单独走代理的场景，可在 **Powertools -> 设置 -> 网络代理** 开启：
- **免改文件、免建快捷方式**：不修改 `app.asar` 也不改动桌面快捷方式，通过协议下拉（`HTTP` / `SOCKS5` / `HTTPS`）+ 主机/IP + 端口三段输入（支持粘贴完整地址自动拆填），在重启 Antigravity 时统一注入 `--proxy-server`、`--proxy-bypass-list` 与 `HTTP_PROXY` / `HTTPS_PROXY` / `NO_PROXY`（强制保底本地回环地址）。
- **连通性测试、冷启动提醒与切号协同**：内置真实 HTTP CONNECT / SOCKS5 隧道测试和重启前端口监听预检，可选 `GODEBUG=http2client=0`（强制 HTTP/1.1 缓解 `Post: EOF` 断连）；下次正常冷启动若检测到代理尚未生效，会在右下角提示一键重启开启；多账号切换与升级重启会自动保留当前代理配置，互不冲突。

## 功能配置说明

所有开关均可在客户端左侧栏 **Powertools -> 设置** 中实时修改并自动持久化（底部支持一键 **恢复默认设置**）。

### 全局开关

| 配置项 | 默认值 | 作用说明 |
| --- | --- | --- |
| 启用 Powertools | 开启 | 插件总开关；关闭后立即暂停所有界面注入与请求增强，保留当前已保存的设置 |

### 界面与显示

| 配置项 | 默认值 | 作用说明 |
| --- | --- | --- |
| 语言 | `简体中文` | 可选 `简体中文` 或 `English`，同时作用于插件面板与客户端常用原生菜单 |
| 紧凑排版 | 开启 | 收紧聊天正文行高、段落留白与工具行高，字号跟随客户端设置 |
| 始终显示会话目录 | 开启 | 在多轮对话左侧常驻显示轮次快速跳转目录，打开右侧概览面板时也不自动隐藏 |
| 切换会话时保持概览 | 开启 | 在不同会话之间切换时，保留右侧概览面板当前的展开状态 |
| 项目默认显示会话数 | `默认 (6)` | 控制侧栏每个项目默认展示的会话数量（可选 `默认 (6)` / `1` / `2` / `3` / `4` / `5` / `10` / `全部展开`），超出部分收起至「查看全部」 |
| 任务栏未读提醒 | 开启 | 后台对话完成时在任务栏标题显示未读数字并触发 Windows 原生高亮提醒，切回查看后自动消除 |
